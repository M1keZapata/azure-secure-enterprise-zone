## Role-Based Access Control (RBAC)

### Azure-Admins

Role:

Contributor

Scope:

Subscription

Purpose:

Provides administrative access to Azure resources.

### Azure-Readers

Role:

Reader

Scope:

Subscription

Purpose:

Provides view-only access to Azure resources.

### Azure-Security

Role:

Security Reader

Scope:

Subscription

Purpose:

Provides access to security-related resources, recommendations, and monitoring data.

## Design Principle

Users receive permissions through group membership rather than direct role assignments.
