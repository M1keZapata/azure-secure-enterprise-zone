# Azure Naming Standards

## Resource Groups

rg-<function>-<environment>

Examples:

rg-hub-prod
rg-spoke-prod
rg-security-prod
rg-monitoring-prod

## Virtual Networks

vnet-<function>-<environment>

Examples:

vnet-hub-prod
vnet-spoke-prod

## Network Security Groups

nsg-<function>-<environment>

Examples:

nsg-management-prod
nsg-servers-prod

## Virtual Machines

vm-<role>-<environment>-<instance>

Examples:

vm-admin-prod-01
vm-web-prod-01

## Storage Accounts

st-<workload>-<environment>

Examples:

st-platform-prod
st-secure-prod

## Log Analytics

law-<function>-<environment>

Examples:

law-monitoring-prod

## Key Vault

kv-<function>-<environment>

Examples:

kv-security-prod
